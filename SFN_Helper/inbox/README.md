# inbox — папка для ваших скриптов

Загружайте сюда свои Lua-скрипты (MoonLoader / SA-MP) — каждый станет
вкладкой общего окна **SFN Helper** в дизайне SFN Logs.

Как загрузить через веб GitHub:
1. откройте эту папку на github.com;
2. **Add file → Upload files**;
3. перетащите файлы `.lua` (и, если есть, `.md`-описания, фикстуры, скриншоты);
4. выберите _Commit directly to the main branch_ → **Commit changes**;
5. напишите мне «скрипты в inbox» — дальше я собираю SFN_Helper.

Требования к именам: латиница, без пробелов (`weather.lua`, `interviews.lua`).
Имя файла = id модуля; заголовок вкладки возьму из шапки скрипта или уточню.

Формат и состояние кода — любые: разберу и приведу к контракту
(см. `SFN_Helper/CONTRACT.md`). Описание «что должно остаться пользователю»
очень помогает: положите рядом `<имя>.md` или напишите в чате.

Файлы здесь остаются как эталон поведения: по ним сверяются реплики, стадии и
форматы данных. В игре они больше не нужны — после установки
`SFN_Helper.lua` их следует выгрузить, иначе окна и хоткеи задвоятся.

Что изменилось при переносе (коротко; подробности — в `CHANGELOG.md` в корне):

* у всех трёх удалены свои `ApplyTheme`/окна — вместо них вкладки общего окна в
  дизайне SFN Logs, свои автоапдейтеры — обновления даёт ядро;
* `decodeJson`, которого не существовало ни в одном из скриптов, заменён общим
  JSON-кодеком ядра: базы, хоткеи и сохранённые тексты наконец читаются после
  перезапуска (раньше `pcall(decodeJson, …)` всегда падал, и файлы молча
  игнорировались);
* база полов стала общей (`SFNHelper\genders.json`) со слиянием из
  `sfn_data\` и `sfn_photo_data\` при первом запуске;
* хоткей «Соцопроса» перенесён с F11 на F10, чтобы не пересекаться с «Эфиром».

Новый скрипт редакции кладите сюда же — он станет вкладкой с `order` больше
30 (см. `SFN_Helper/CONTRACT.md`).
